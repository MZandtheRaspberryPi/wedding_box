# wedding_box

The wedding box was designed in Fusion360 and fabricated in London at my home lab. It uses Adafruit's circuit python and a Pi PICO 2W as the microcontroller. The code that gets uploaded to the box is in the `software/circuitpy` subfolder. Documentation and example code for client applications to control the box is in the `software/client` subfolder.
